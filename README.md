# Django E-commerce Web Application

A full-stack E-commerce web application built using **Python, Django, and MySQL**. This project demonstrates backend development concepts including authentication, database management, session handling, and order processing.

---

## Features

- User Registration and Login
- Secure Authentication and Session Management
- Product Listing
- Product Detail Page
- Shopping Cart
- Order Management
- Admin Panel
- CRUD Operations
- MySQL Database Integration
- Django MVT Architecture

## Installation

### Clone the repository

```bash
git clone https://github.com/Sunil-Patidar000/<repository-name>.git
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Run Development Server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
